## U1 detail — the actual command unit chain today

Producers (all funnel through `Robot.cs:38-48` → `:119-130`):

| Producer | Shoot | Chip | Implied unit |
|---|---|---|---|
| Attacker direct shot (`AttackerDecision.cs:214-221`) | `AttackerKickSpeed` (code 6500 / config 6000) **or sentinel `1.0f`** | 0 | mm/s |
| Attacker pass (`:234-242`) | `PassKickSpeed` (code 3000 / config 4000) | `PassChipSpeed` (code **2000** / config **35**) | mm/s / power |
| Attacker defensive (`:223-232`) | 0 | `DefensiveChipSpeed` (code **2000** / config **80**) | power |
| Goalie clear/dive (`Goalie.cs:216,242`), Defender dive (`Defender.cs:208`) | 0 | 150 | NRF power 0–150 |
| OurFreekick (`:23-27`) | 0 | 50 | NRF power |
| CircleBall / kickoff / BallPlacement | 3000 | 0 | mm/s |
| ManualControl (`:71-72,455-466`) | 6 (**m/s**) | 4 (**meters**) | m/s, m |

Consumers:

| Consumer | Shoot | Chip |
|---|---|---|
| `Nrf` (**enabled**, `config.toml:456`; `Nrf.cs:83-105`) | mm/s → clamp 6500 → /1000 → `ShootCalibration` → byte | clamp 0–150 → `ShootCalibration` → byte |
| `Simulator` (disabled; `Simulator.cs:50-61,75`) | forwarded raw as m/s (6000 ⇒ grSim max) | `Chip*5` as m/s (35→175, 150→750: nonsense) |
| `ZmqRobotSender` (**enabled**, `:478`; `ZmqRobotSender.cs:92-93`) | wire **`Chip`** ← `Shoot*0.7/1000` | wire **`Shoot`** ← `5.0f` iff `Chip>10 && Shoot==0` |

Consequences not stated in July:
- On the ZMQ path chip is **binary** — the tuned 35/80/150/50 values are indistinguishable.
- Manual control is **non-functional on real robots**: kick 6 → wire `0.0042`; chip 4 fails `>10` → never chips.
- Code defaults for `PassChipSpeed`/`DefensiveChipSpeed` are ~50× off the shipped config, so a checkout without `Data/config.toml` behaves nothing like the competition setup.
- **Nrf and Zmq are both enabled** in the shipped config with mutually inconsistent conventions, while `Nrf.cs:9` still says "untested".
- Same class of bug on the dribbler: `BallControl.cs:13` writes firmware level `2`, forwarded raw to grSim's rad/s `DribblerSpeed` (`Simulator.cs:77`).
